# Mom's Sewing Shop

Sitio web para un taller de costura familiar en Querétaro.

## Descripción

Web informativa que muestra servicios, galería de trabajos, información de contacto y formulario.

## Tecnologías

- HTML
- CSS
- JavaScript
- Git/GitHub
- GitHub Pages

## Estructura

- `index.html` - Página de inicio
- `servicios.html` - Servicios ofrecidos
- `galeria.html` - Galería de trabajos
- `acerca-de.html` - Información del negocio
- `contacto.html` - Formulario y contacto
- `politicas.html` - Políticas de entrega y precios
- `css/` - Estilos
- `js/` - Scripts
